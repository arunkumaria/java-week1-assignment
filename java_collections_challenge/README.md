# Java Collections Challenge

## Objective
A console-based Java application designed to improve familiarity with commonly used Java collections and their practical use cases.  
The project demonstrates how to use **ArrayList**, **HashMap**, and **Queue** interactively with menu-driven operations.

## Features Implemented
- **ArrayList Challenge**
  - Add elements
  - Remove elements
  - Update elements
  - Search for an element
  - Iterate and display contents
- **HashMap Challenge**
  - Insert key-value pairs
  - Retrieve a value using a key
  - Update a value
  - Check whether a key exists
  - Iterate through entries
- **Queue Challenge**
  - Add items to queue
  - Remove items from queue
  - Peek at the front item
  - Display queue contents
- Interactive menus for each challenge
- Clean and readable output with clear prompts

## Technologies Used
- Java (JDK 17 or higher recommended)
- Collections Framework (`ArrayList`, `HashMap`, `Queue`)
- Console I/O (`Scanner`)
- Exception handling for invalid inputs
- Object-Oriented Programming principles (Encapsulation, Constructors, Methods)
